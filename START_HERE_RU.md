# Запуск NEXUS-IT

1. Откройте папку `NEXUS-IT` в VS Code.
2. В терминале выполните `npm install`, затем `npm run dev`.
3. Откройте адрес из терминала (обычно http://localhost:5173/).
4. Для тестов выполните `npm test`, для сборки — `npm run build`.

Подробности и список функций находятся в `README.md`. Краткое выступление для преподавателя — в `DEFENSE_RU.md`.

В ZIP каждый проект лежит в своей отдельной папке. Внутри папок вложенных каталогов нет.
