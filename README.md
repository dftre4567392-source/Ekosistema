# NEXUS / IT — учебный информационный сайт

## О проекте

NEXUS / IT — адаптивный сайт-путеводитель по IT-индустрии. Пользователь может изучить направления, узнать, чем занимаются специалисты, и познакомиться с компаниями, работающими в сфере технологий. Это **учебный проект**, а не официальный сайт указанных компаний.

## Технологии

- **React 18** — создание интерфейса из компонентов и обновление карточек без перезагрузки страницы.
- **JavaScript (ES-модули и JSX)** — структура данных, поиск, раскрывающиеся описания.
- **CSS** — тёмный технологичный главный экран, карточки, сетки, адаптивность и анимации при наведении.
- **Vite 5** — запуск проекта и сборка.
- **node:test** — автоматические проверки поиска (входит в Node.js).

## Реализованные возможности

1. Навигация по пяти разделам: обзор, направления IT, профессии, компании и о проекте.
2. **7 направлений**: программирование, AI, кибербезопасность, веб-разработка, разработка приложений, облако и данные.
3. **7 профессий**, включая frontend, backend, fullstack и AI-разработчика.
4. **6 компаний**: Google, Microsoft, NVIDIA, Apple, Яндекс и OpenAI.
5. Общий поиск по направлениям и профессиям: учитываются названия, описания, теги и навыки.
6. Кнопки раскрытия подробностей карточек направлений и профессий; сброс поиска.
7. Адаптация под мобильные устройства, клавиатурная навигация и учёт настройки уменьшения анимаций.

## Как запустить проект

В VS Code откройте **папку `NEXUS-IT`** (именно её, а не другой проект). Откройте терминал и выполните:

```bash
npm install
npm run dev
```

Откройте адрес, показанный в терминале (обычно `http://localhost:5173/`).

Проверка тестов — `npm test`, сборка — `npm run build`, просмотр сборки — `npm run preview`.

## Где лежат файлы

Все исходные файлы находятся **непосредственно внутри папки `NEXUS-IT`**, без вложенных папок `src`, `public` или `components`.

- `index.html` — входная страница сайта.
- `nexus-main.jsx` — запуск React.
- `nexus-App.jsx` — главная структура интерфейса.
- `nexus-style.css` — стили и адаптивность.
- Остальные `nexus-*.jsx` / `nexus-*.js` — компоненты, данные и функции.
- `DEFENSE_RU.md` — простое объяснение для защиты.

После `npm install` появится служебная папка `node_modules`, а после `npm run build` — `dist`. Это нормально: npm и Vite создают их автоматически. **В скачиваемом архиве вложенных папок внутри проектов нет.**

## Ограничения

Проект учебный, описания компаний и направлений — ознакомительные. Веб-шрифты загружаются при наличии интернета.
